# 领域手册 · 高考分数分布数据（口径与定义）

> 本手册只统一**概念口径与字段定义**，帮助你在计算时消除歧义。
> 它**不提供分析方法、模型选择或解题步骤**——那是本题要考察的能力。
> 真实工作中分析师也有这样一份"数据字典 + 业务口径说明"可查。

---

## 一、数据字段字典

CSV 每一行是「某省 × 某年 × 某科类」下的**一个分数点**的人数分布记录。

| 字段 | 含义 | 口径说明 |
|---|---|---|
| `最高分` / `最低分` | 该记录分数区间的上下界 | 多数行两者相等，即"某一具体分数"；个别行是分数段 |
| `人数` | 落在该分数（段）的考生人数 | **可能为空**：空表示该分数点无单独统计，按缺失处理 |
| `累计` | 从最高分往下到本行的累计人数 | 即该分数对应的**位次**（rank）上界 |
| `省级行政区` | 省/自治区/直辖市名称 | 共 31 个；名称以数据内实际值为准 |
| `科类` | 文科/理科/物理类/历史类/综合等 | 见下方"科类口径映射" |
| `年份` | 考试年份 | 数据含 2000 年以前的少量脏数据，需按清洗规则处理 |
| `满分(裸分)` | 该年该省该科类的卷面满分 | 用于跨年可比时的归一化参考；不同省不同年可不同 |
| `模式` | 高考科目组合模式 | 如 `3+X`、`3+1+2`、`3+3` 等 |

## 二、数据清洗口径（统一，避免各模型口径不一）

以下是**本数据集约定的清洗口径**，请据此清洗后再计算 part1 的汇总量：

1. **无效模式行**：`模式` 字段为空、`N/A`、`NA`、`null` 的行视为脏数据，**剔除**。
2. **年份越界行**：`年份 < 2000` 的行视为脏数据，**剔除**。
3. **人数缺失**：`人数` 为空的行，其人数按 **0** 填充（保留该行的分数/位次信息，仅人数计 0）。
4. `cleaned_records` = 完成上述清洗后**剩余的行数**。
5. `missing_count` = 清洗过程中**因人数缺失被填 0 的行数**（不含被整行剔除的行）。

> 说明：`total_records` 指清洗**前**的原始总行数；`cleaned_records` 指清洗**后**的行数。二者定义不同，勿混用。

## 三、统计量口径（关键——不写清会造成"口径分"而非"能力分"差异）

本数据是**分组频数数据**（每行带一个 `人数` 权重），因此所有均值/方差都是**加权**统计量。请统一采用以下公式，否则同一份正确分析会因口径不同而落到不同容差档。

### 3.1 加权均值

加权均值 = (Σ wᵢ·xᵢ) / (Σ wᵢ)

其中 xᵢ 取该行分数（`最高分`与`最低分`相等时即该分数；为分数段时取两者中点），wᵢ 为该行 `人数`。

### 3.2 加权标准差 —— 用**总体口径**（分母 Σwᵢ，不是 Σwᵢ − 1）

加权标准差 σ_w = sqrt( Σ wᵢ·(xᵢ − 均值)² / Σ wᵢ )

> 这是本手册**最重要**的一条口径：分母用 Σwᵢ（总体方差），**不要**用 Σwᵢ − 1（样本无偏估计）。二者在大样本下差异很小，但足以跨越 ±0.5% 的容差档，从而把"口径选择"误判成"能力差异"。

### 3.3 高分段人数（如"600 分以上"）

指清洗后、**加权**（按 `人数`）统计的、分数 ≥ 阈值的**考生总人数**，不是行数。

### 3.4 比值类指标（如"物理/历史类人数比"、"理科/文科比"）

ratio = 分子类别的加权人数 / 分母类别的加权人数

分子分母的类别口径见下方"科类口径映射"。

### 3.5 "改革方向"（direction）判断口径

`reform_direction` 是对**同口径**下改革前后三个指标变化方向的判断，取值只能是 `up` / `down` / `flat`：

| 指标 | 判断依据 |
|---|---|
| `mean` | 改革后加权均值 相对 改革前 是升/降/持平 |
| `std` | 改革后加权标准差 相对 改革前 是升/降/持平 |
| `high_score_share` | 改革后高分段占比 相对 改革前 是升/降/持平 |

> **同口径**指：比较时须把改革前后映射到**可比的科类**（见 3.6），不能拿"改革前理科"直接比"改革后全体"。

### 3.6 科类口径映射（新旧高考可比）

新旧高考科类命名不同，跨改革比较时按下表归入可比大类：

| 旧高考 | 新高考（3+1+2 / 3+3） | 归入可比类 |
|---|---|---|
| 理科 | 物理类（首选物理） | **理工方向** |
| 文科 | 历史类（首选历史） | **人文方向** |
| 综合 / 其他 | 综合 / 其他 | 按原样，不强行归类 |

> 例：比较"改革前后理工方向均分"时，改革前取 `科类=理科`，改革后取 `科类=物理类`。

- 用哪种因果推断方法、如何选对照组、如何做安慰剂/敏感性检验
- 用什么方法估计尾部指数、分布距离、区间覆盖

以上都由你自行决定并在 `outcome.json` 中给出——这正是本题区分模型能力的地方。
