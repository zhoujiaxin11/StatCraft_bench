# 全国高考分数分布——改革影响、位次预测与因果推断

## 任务背景

你是一名教育数据分析顾问。客户提供了全国 31 个省级行政区、跨多个年份（约 2000–2025）的高考"一分一段表"数据。客户希望回答两个层次的问题：

1. **改革影响**：2021 年前后多省从旧高考（`3+X` 文理分科）切换到新高考（`3+1+2` 物理类/历史类），这次改革对分数分布产生了什么可量化的影响？
2. **预测与因果**：能否构建预测模型服务于志愿填报？改革与高分段人数变化之间存在因果关系吗？

## 数据

数据文件：`environment/2000_2025_gaokao_score_distribution_11_11_2025.csv`（约 53 万行）。

### 字段定义
| 字段 | 含义 |
|------|------|
| `最高分` / `最低分` | 分数段上下界（一分一段时二者相等） |
| `人数` | 该分数段人数（部分行可能缺失） |
| `累计` | 从最高分累计到该分数的人数（位次） |
| `省级行政区` | 省份 |
| `科类` | 文科 / 理科（旧高考）、物理类 / 历史类（新高考）、综合、其他 |
| `年份` | 数据年份 |
| `满分(裸分)` | 该省该年满分（各省差异较大） |
| `模式` | `3+X` / `3+3` / `3+1+2` 等 |

数据存在需处理的情况：异常年份记录、人数缺失、口径变迁、满分差异。请自行判断并处理。

## 分析任务

### Part 1: 数据概览

评估数据基本情况：覆盖范围、异常识别、缺失处理、模式分布。给出清洗前后的记录数。

### Part 2: 高考改革影响

选择一个观察对象作为改革影响的量化案例，说明选择依据。建议选取在 2021 年前后从旧高考（`3+X` 文理分科）干净切换到新高考（`3+1+2` 物理类 / 历史类）、且**只有一个无过渡年份的单一切换点**的省份作为案例（例如 **河北**：2020 年仍为 `3+X`，2021 年起为 `3+1+2`），这样前后同科类（理科 → 物理类）的分数分布对比最干净，因果效应估计受历史惯性干扰最小；选多省混合反而会引入各批次改革时点不一致与满分差异带来的噪声。确定后请显式说明所选省份及理由。分析至少覆盖：

- 选科结构变化（旧口径 vs 新口径的比例对比）
- 分数分布形态变化（集中趋势、离散程度、高分段占比）
- 改革推行的时间线（不同批次省份进入新模式的年份）

具体统计口径与观察维度由你判断。

### Part 3: 高分段人数预测模型

构建回归模型，**预测每个（省份, 科类, 年份）组合的高分段人数**（该组合下 `最高分 ≥ 600` 的 `人数` 之和）。这是一个聚合量级目标，无法从单行直接推出。

约束：
- 特征工程自行设计，但**不得使用会导致目标泄漏的特征**（例如从当行 `人数`/`累计`/位次派生的特征）
- 划分训练/测试集时**必须按时间划分**，测试集必须包含 2024 与 2025 年
- 报告测试集 R²、RMSE、MAE 与 Top 5 特征重要性
- 将测试集预测结果保存为 `output/predictions.csv`（列：`省份, 科类, 年份, y_true, y_pred`，每个组合一行）

### Part 4: 改革因果效应

用**多种因果推断方法交叉验证** 3+1+2 改革对高分段人数的因果效应。要求：

- 自行定义处理组与控制组，说明选择依据
- 使用至少两种独立方法估计因果效应
- 进行安慰剂检验与稳健性检验
- 检验平行趋势假设是否成立
- 综合判断改革是否存在因果效应，效应方向如何

具体方法选择、时点划分、样本约束（如满分口径）由你判断。

### Part 5: 高阶统计量与不确定性

给出以下四方面的量化：

- 高分段的尾部厚度（用某种极值方法刻画）
- 改革效应的稳健推断（考虑省份层面异质性）
- 改革前后分数分布的距离/差异度量
- 预测的不确定性量化（构造 80% 预测区间，评估经验覆盖率）

具体方法选择由你判断。

## 输出

汇总结果保存为 `outcome.json`（工作目录根）。答案字段的类型定义见 `schema.json`。要求：

- 所有数值必须为 JSON number（不要用引号包起来）
- 文字说明字段用字符串
- 未做出的字段可省略或填 null，但会被计 0 分

同时保存 `output/predictions.csv`（Part 3 要求）。
